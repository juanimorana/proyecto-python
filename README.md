## 📌 Descripción

Proyecto desarrollado en Python utilizando **FastAPI** y **Pydantic**, aplicando validación de esquemas de datos y estructuras tipadas (`BaseModel`, `Field`).

El trabajo busca aplicar:
* diseño de APIs web de alto rendimiento con FastAPI
* validación de datos de entrada (nombres con longitud mínima, precios positivos mayores a 0)
* modelado de entidades (`ProductoCrear`, `ProductoDB`)
* manejo de endpoints y respuestas estructuradas

## 🛠️ Tecnologías utilizadas
- **Lenguaje:** Python
- **Framework Web:** FastAPI
- **Validación de datos:** Pydantic
- **Control de Versiones:** Git / GitHub
